# WoodFlow — Release Checklist

Ten dokument jest używany przy KAŻDYM wydaniu (v0.1, v0.2, v0.5,
v1.0, v2.0...) — nie jest jednorazową listą przed premierą. Przy
każdym release kopiuj sekcję odpowiadającą docelowej fazie i
zaznaczaj checkboxy w PR/commit opisie.

## MVP

- [ ] Privacy Policy (UK GDPR)
- [ ] Terms of Service
- [ ] Licencje Open Source
- [ ] About (wersja, build, data wydania)
- [ ] Contact
- [ ] Version widoczny w Ustawieniach
- [ ] Crash reporting
- [ ] Backup — test działania
- [ ] Restore — test działania
- [ ] `flutter analyze` = 0 warnings
- [ ] `flutter test` = PASS

## Beta

- [ ] Feedback (formularz lub mailto)
- [ ] Report Bug (mailto: z auto-uzupełnionymi danymi urządzenia)
- [ ] Feature Request (mailto)
- [ ] FAQ
- [ ] Changelog widoczny w aplikacji
- [ ] Analytics (podstawowe — otwarcia ekranów, nie dane osobowe)

## Production

- [ ] Cloud Backup
- [ ] User Accounts
- [ ] Roles
- [ ] Permissions
- [ ] GDPR — Data Export
- [ ] GDPR — Delete Account
- [ ] Penetration Testing
- [ ] Performance Testing
